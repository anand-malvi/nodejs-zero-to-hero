# CommonJS Learning Project

This project demonstrates how CommonJS modules work in Node.js.  
It includes a calculator module and a set of practice exercises.

---

## Project Structure

    └── Answers/
        ├── demo.js
        ├── Task_1.js
        ├── Task_2.js
        └── Task_3.js

---

## Overview

This project helps you understand:

- How to export functions using `module.exports`  
- How to import modules using `require()`  
- How to split code into multiple files  
- How to structure a simple Node.js project

---

## Calculator Module

`Calculator.js` exports four functions:

- add(a, b)  
- subtract(a, b)  
- multiply(a, b)  
- divide(a, b)  

These functions are imported and used in `main.js`.
